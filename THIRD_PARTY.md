# Third-party material

okbot's own code is MIT OR Apache-2.0. Release archives also contain
`THIRD_PARTY_LICENSES.md`, generated by `cargo about` from the Rust crates compiled into the
binary (the allowed licenses are listed in `about.toml` and `deny.toml`).

The default knowledge bundle (`crates/okbot-knowledge/template/`) is original to okbot and
licensed like the rest of the repository.
