# Release checklist — v0.12.0

The eighth release, for operators who drive okbot from their own tools. Fixed `[[command]]` results
and `[[notify]]` messages can show cards, tables, charts, links and buttons without the agent
(ADR 0017, #58). `okbot task` and `okbot people` print JSON, and a task can belong to the person
behind a signed run token (#59). Every reserved `[[command]]` name is reported at once and
`okbot commands --builtin` lists them (#60). A running bot reloads its access lists when
`okbot.toml` changes, or through `okbot reload` (ADR 0018, #61). It follows
`docs/implementation-plan.md` Part 5 and `docs/releasing.md`. Status as of 2026-10-30; ✅ done,
⏳ to do, ⚠️ done with a caveat.

## 3. Security review of the diff since v0.11.0

| | Item | Status |
|---|---|---|
| 3.1 | Review of `git diff v0.11.0..main` (command and notify views, button presses and approvals, access reload, run tokens in the CLI) | ✅ 2026-10-30 |
| 3.2 | Findings fixed or listed as known issues | ✅ fixed before the release (#62) |

Fixed (Medium): a button's label could hide which `[[command]]` it ran, so a `[[notify]]` token or
an MCP server returning third-party text could get an admin to run another server's command. Buttons
now run only commands of the same `[[mcp]]` server, `[[notify]]` buttons need the route's
`commands` list, views come only from `structuredContent`, and every native view shows the
commands its buttons run.

Fixed (Low): an approved press ran as the approving admin (now as the presser, whose rights are
checked again); approval views lived 7 days with a snapshot of the approvers (now 10 minutes, and the
approvers are checked against the current lists); the watcher could read a half-written
`okbot.toml` (okbot now replaces the file with a rename and reloads only settled changes).

Sound: built-ins never reachable from a button; presses go through the gate, `may_run` and roles of
the presser; a failed reload keeps the old lists; no runtime reader of the access lists left on the
start-up copy; `--run-token` checks signature, expiry, bot and server (it picks an owner and is not
a permission check, as the guide says).
