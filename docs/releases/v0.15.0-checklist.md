# Release checklist — v0.15.0

A minor release: **app hints, better tasks and schedule apps, and artifacts** (ADR 0021,
`docs/design-app-hints.md`, `docs/design-artifacts.md`). It follows `docs/implementation-plan.md`
Part 5 and `docs/releasing.md`. Status as of 2026-11-28 (release PR); ✅ done, ⏳ to do, ⚠️ done with a caveat.

What is in it (PRs #92–#97, merged in that order):
- **App hints** (#93): each app says when it helps (`[agent] use_when` in `app.toml`). The agent is
  told which apps the person can open here. A long `task_list`, `memory_list` or `artifact_list`
  result ends with `see_also`, so the agent offers the app instead of pasting everything.
- **Tasks and schedule** (#94): tasks are edited in place (title, notes, due, reminder, repeat);
  the schedule app adds a calendar view (7 or 30 days) beside the agenda.
- **Artifacts** (#95–#97):
  - The agent saves pages, documents, tables and diagrams as versioned files in
    `kb/artifacts/`, in seven kinds: HTML, Markdown, SVG, Mermaid, CSV, JSON and text.
  - The reply that saved one gets an Open button.
  - The built-in `artifacts` app opens HTML, SVG and Mermaid in a viewer with no network.
    Mermaid 12.3.0 is vendored.
  - New commands: `/artifacts` in chat, `okbot artifact list|show|export|rm` in the terminal.
  - `okbot doctor` reports artifact use against the quotas.

| | Item | Status |

| 3.1 | Review of `git diff v0.14.0..main`: the artifact tools and store paths, viewer route and grants, CSP (no `frame-ancestors`, see below), `frame-src` only for the built-in app, download headers, `/app <name> <id>`, `see_also` text in tool results | ✅ 2026-11-28 |
| 3.2 | Findings fixed or listed as known issues | ✅ no vulnerability found. One functional gap was fixed (#99): `kb_query` could not find artifacts, because the requester scope left out `artifacts/`. It now follows the rules for tasks |

Known and documented in `docs/design-artifacts.md`:
- The viewer sends no `frame-ancestors`. Its parent frame is sandboxed with an opaque origin, which
  no source expression matches, so browsers refused every embedding. The defence is the secret,
  10-minute, one-version link and the viewer's own sandbox (`connect-src 'none'`, no cookies).
- HTML artifacts run their own scripts by default. They have no network, no App API and no
  cookies. `[artifacts] scripts = false` turns scripts off.
