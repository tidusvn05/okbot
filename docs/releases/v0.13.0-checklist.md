# Release checklist — v0.13.0

The ninth release. Restricted Claude runs no longer see the git status of the bot directory
(agent-call 0.5.1), and `okbot doctor` warns when `state_dir` is inside a git repository (#71, #73).
Discord moves to twilight 0.18, and okbase 0.2.6 brings rmcp 3.10 and SQLite 3.54 for new security
advisories (#72). It follows `docs/implementation-plan.md` Part 5 and `docs/releasing.md`. Status
as of 2026-11-15; ✅ done, ⏳ to do, ⚠️ done with a caveat.
