# Memory

Say "remember that …" and the bot saves a short note. Notes can be:

- **personal**: about you, used only when you talk to the bot;
- **chat**: about the current group chat, used only in that chat;
- **team**: useful for everyone, used in every chat.

Say "forget …" to remove a note. The operator can review and undo every note.
