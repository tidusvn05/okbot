# Index: memory

## Subdirectories
* [global](/memory/global/index.md) - Team-wide notes.
* [people](/memory/people/index.md) - Notes about one person, shared by their linked accounts.
* [rooms](/memory/rooms/index.md) - Notes about one chat.
* [users](/memory/users/index.md) - Notes about one person.
